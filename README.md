# 漫屿

面向 HarmonyOS 的原生多书源漫画阅读器。

## 功能

- **书架**：作品归一、来源关联、分类、筛选、排序、批量管理及换源。
- **更新**：检查书架作品的新章节，查看最近阅读记录。
- **书源**：内置在线书源，连接 Suwayomi 服务，导入本地 CBZ、ZIP 或图片。各书源独立启停、浏览和设置。
- **阅读**：连续纵向、纵向翻页、从左向右、从右向左与双页阅读；支持封面偏移、宽图单页、裁白边、护眼遮罩、九宫格点按、书签等。
- **离线**：下载完整漫画后在应用内阅读，并可导出 CBZ。
